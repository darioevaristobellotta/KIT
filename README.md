# Next.js Developer Kit by Dario Evaristo Bellotta

Das wiederverwendbare, minimalistische **Next.js Developer Kit** für saubere, moderne und performante Webanwendungen.

## 🚀 Features

- **Next.js 16 (App Router)** & **React 19**
- **Google Material Design 3 Styling**: Pure Vanilla CSS, HSL-Farbsystem, Material Design Radii, Shadows & Easing Animations
- **Nav & Header**: Responsive Header aus LearnQuizDB mit Mobile Burger-Menü & Dropdown-Navigation
- **Footer**: Kompletter Footer mit Social-Media-Links (Instagram, YouTube, LinkedIn) und Impressum / Datenschutz
- **SEO & Schema.org**: Vorkonfiguriertes Schema.org JSON-LD (`WebSite`, `Organization`, `Person`) & Next.js Metadata API
- **GDPR Cookie Banner**: Einverständnisverwaltung für Analytics / Google Tag Manager
- **Optimierte Fonts**: `Inter` & `Libre Baskerville` via `next/font/google`

## 🛠️ Quickstart

1. **Abhängigkeiten installieren:**
   ```bash
   npm install
   ```

2. **Entwicklungsserver starten:**
   ```bash
   npm run dev
   ```
   Öffne [http://localhost:3000](http://localhost:3000) im Browser.

3. **Production Build erstellen:**
   ```bash
   npm run build
   npm start
   ```
